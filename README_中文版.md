# 照片筛选 · PhotoCurator 中文桌面版

这是基于开源项目 **Photo Curator v7.0** 的中文桌面化二次创作版本。

## 当前版本

- 中文桌面版：**v1.0.0-cn.1**
- 上游基础：Photo Curator v7.0
- 核心流程：**模糊筛选 → 相似去重 → 智能优选**
- 支持：JPEG / PNG / HEIC / HEIF / HIF / TIFF / BMP / WebP / 常见 RAW（CR2、CR3、NEF、ARW、DNG、RAF、ORF、RW2、PEF 等）
- 运行方式：默认使用 **独立桌面窗口**，不需要手动打开浏览器
- 数据处理：本地运行，照片不会上传到云端

## Windows 推荐使用方式

### 第一次使用

双击：

**`一键安装并启动.bat`**

程序会自动：

1. 检查 Python 3.9+
2. 创建项目专用的 `.venv` 独立环境
3. 安装全部依赖
4. 安装桌面窗口组件 pywebview
5. 启动“照片筛选”独立窗口

首次安装完成后，以后不需要重复安装。

### 日常启动

双击：

**`启动照片筛选.bat`**

程序会直接以无控制台黑框的方式打开独立窗口。

### 如果独立窗口打不开

双击：

**`浏览器兼容模式.bat`**

它会使用原有 Flask 方式启动，并打开：

`http://127.0.0.1:5014`

这个入口主要用于兼容和排错，不是默认使用方式。

### 查看启动错误

双击：

**`调试运行.bat`**

如果使用无黑框启动失败，程序也会在项目目录写入：

`启动错误.log`

## 三个主要功能

### 1. 模糊筛选

检测失焦、明显模糊照片，并分成：

- 清晰
- 轻微软（可保留）
- 模糊

默认只做分析和标记。只有用户主动执行移动操作后，文件才会移动到 `Blurred/`。

### 2. 相似去重

识别连拍、近似构图和高度相似照片，将相似照片归组，并优先保留组内更清晰的一张。

可选择 RAW + JPG 同帧照片保留策略。

### 3. 智能优选

从以下维度综合评分：

- 综合观感
- 构图
- 技术质量
- 清晰度
- 色彩

最终可以筛出前 N 张照片，并支持导出。

## 目录入口说明

- `desktop_app.py`：中文桌面窗口启动器
- `photo_curator.py`：核心 Flask 服务、UI 与主流程
- `photo_dedup_batch.py`：相似照片去重
- `photo_ranking_v3.py`：智能评分
- `photo_file_organizer.py`：照片移动与整理
- `raw_loader.py`：RAW / HEIC 加载
- `requirements.txt`：运行依赖
- `vendor/`：地图前端本地资源
