> 面向大图库的 Windows 照片清理工具。v1.5.0 将主流程收敛为 **模糊废片筛选 → 相似照片筛选 → 软件回收站复核**，并重构前后台运行机制。

## 产品定位

PhotoCurator 的两个核心任务：

1. **模糊废片筛选**：快速找到明显模糊、失焦或质量不足的照片并人工复核。
2. **相似 / 重复照片筛选**：把连拍和高度相似照片归组，快速删除不需要的版本。

评分 / 精选推荐不再参与默认清理主流程，作为工具箱扩展功能保留。

支持 JPEG、PNG、WebP、TIFF、BMP、HEIC/HEIF/HIF，以及 CR2、CR3、NEF、ARW、DNG、RAF、ORF、RW2、PEF 等常见 RAW 格式。

## v1.5.0 运行架构

### 前台优先

前台负责：
- 照片展示与大图预览
- 用户筛选决策
- 即时状态反馈
- 当前工作区的局部更新

耗时文件操作不会再阻塞筛图界面。

### 后台任务中心

后台负责：
- 移入软件回收站
- 恢复与永久删除
- 数据库、索引与操作日志
- 清晰度分析
- 相似特征分析
- 缩略图与缓存维护

重要文件任务通过持久化任务队列执行，具有任务状态、优先级、幂等保护和异常恢复能力。程序异常退出后，未完成的重要任务可重新进入队列。

### 双核心并行

默认“开始分析”同时启动：
- 模糊 / 清晰度分析
- 相似 / 重复照片分析

两条核心分析可以并行运行，用户不必先完成一整轮模糊筛选再开始重复照片筛选。前台在后台运行期间保持可操作。

### 稳定前台结果

后台分析结果不会再以“每分析一张就重绘一次页面”的方式干扰当前工作区：
- 当前视图保持稳定
- 后台结果先缓存
- 用户按需加载最新结果
- 相似组按状态分区、分块载入
- 大图库限制单次前台渲染量

## 核心工作区

### 模糊废片

- 清晰 / 轻微软 / 模糊三级结果
- 用户决策高于算法建议
- 点击照片打开大图
- 删除默认进入 PhotoCurator 软件回收站
- 批量处理也进入后台任务队列
- 扫描 / 分析时仍可继续复核已有结果

### 相似照片

相似组具有持久化生命周期：
- **待筛选**
- **已筛选**
- **已筛选 · 有新增**

已经筛选过的组不会重新混回“待筛选”。

如果后来在其它文件夹扫描到新的相似成员，原组会保留历史决策并进入“有新增”状态，不会静默覆盖原结果。

照片生命周期也独立持久化：
- 正常
- 待移入回收站
- 已移入回收站
- 待恢复
- 已永久删除

已移入软件回收站的成员仍可在原相似组中保留历史关系，用于复核和恢复。

### 软件回收站

所有普通“删除”默认进入：

`PhotoCurator_RecycleBin（软件回收站）`

支持：
- 单张 / 批量恢复
- 单张永久删除
- 清空软件回收站
- 缩略图和大图最终复核

删除确认弹窗中：
- **Enter**：移入软件回收站
- **P**：彻底删除
- **Esc**：取消

软件回收站目录自动排除在后续扫描之外。

每个图库的软件回收站还保存 `.photocurator-trash.json` 恢复清单，使原路径信息不只依赖安装目录中的数据库；重装或清理程序配置后仍具备恢复元数据。

## 工具箱

低频、辅助和扩展能力集中在工具箱：

- 照片评分 / 精选推荐
- 完整系统运行日志
- 后续诊断与实验性能力

主题颜色切换已从 v1.5.0 主架构中移除，软件使用统一视觉系统。

## 界面与布局

v1.5.0 的布局原则：

- **照片工作区最大化**
- 主流程、设置、后台任务、工具箱职责分离
- 左侧导航可折叠
- 照片来源、筛选设置、统计信息可折叠
- 后台任务轻量展示，不抢主工作区
- 相似结果使用有限窗口 + 按状态分区 + 按需加载
- 页面重新获得焦点或后台任务完成后自动同步，不依赖手动刷新
- 保持浅色极光 + iOS 毛玻璃视觉体系，但避免高成本动效干扰大图库性能

## Windows 桌面运行

- 单实例运行
- 默认最大化启动
- Ctrl + 鼠标滚轮仅调整照片缩略图尺寸
- 大图内滚轮缩放、拖动平移、双击适配 / 2x
- 关闭主窗口时进入 Windows 系统托盘，后台任务继续
- 托盘可恢复 PhotoCurator 或明确退出
- 最小化与关闭到后台是不同动作
- 正式 C 图标用于 EXE、安装包、快捷方式和托盘
- 动态本地端口
- 启动错误日志

## 本地数据结构

核心数据继续使用本地 SQLite，并按职责划分：

- 分析缓存：清晰度、评分、相似特征等可重建数据
- 用户决策：照片生命周期与人工状态
- 相似组：稳定组身份、组状态与历史成员
- 后台任务：queued / running / done / failed
- 操作日志：关键用户操作和后台处理记录
- 软件回收站：中央索引 + 图库内独立恢复清单

原则：**算法结果可以重算，用户决策不能被重算覆盖。**

## 内置测试数据

正式程序继续自带 12 张基准测试照片：
- 清晰 4 张
- 轻微软 4 张
- 模糊 4 张

用于回归测试状态切换、软件回收站、相似组选优、前后台任务和 UI。

- 保留设置

## 安全边界

默认原则：**先分析、再审核、普通删除可恢复，永久删除必须明确确认。**

- 普通删除不进入 Windows 回收站，而进入 PhotoCurator 软件回收站
- 永久删除是独立危险操作
- 恢复时不覆盖已有同名文件
- 软件生成目录不会重新进入扫描
- 照片分析、缩略图、RAW / HEIC 解码在本机执行
- GPS 地图功能如启用，可能向地图 / 地理编码服务发送经纬度，但不会上传照片文件
