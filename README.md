## 主要能力

核心流程保持原项目算法逻辑：

**统一照片整理工作区：清晰度分析 + 相似组选优 + 精选推荐**

支持 JPEG、PNG、WebP、TIFF、BMP、HEIC/HEIF/HIF，以及常见 RAW：CR2、CR3、NEF、ARW、DNG、RAF、ORF、RW2、PEF 等。

主要改进：

- 独立桌面窗口，不需要手动打开 localhost 网页
- Windows 原生文件夹选择
- 中文界面、中文状态提示和中文错误提示
- Windows 125% / 150% / 200% DPI 响应式适配
- 默认最大化启动
- 主图库支持 Ctrl + 鼠标滚轮调整缩略图尺寸，不再缩放整个界面
- 中小窗口自动调整侧栏、照片网格和大图详情布局
- 支持“当前文件夹”或“当前文件夹 + 所有子文件夹”递归扫描
- 递归结果按来源文件夹分组，并支持全部展开 / 全部收起
- 结果支持网格 / 列表查看；Ctrl + 鼠标滚轮动态调整缩略图大小
- 相似去重支持“文件夹内对比 / 全局对比”
- 相似组先自动筛选，再人工复核；每组可同时保留多张照片
- 取消传统分页，按来源文件夹累计展示并结合缩略图懒加载
- 运行期间限制实时照片数据量，降低长时间筛选后的页面卡顿
- 去重缓存保存到系统临时目录，不污染照片文件夹
- 手动修改“清晰 / 轻微软 / 模糊”只改变分类，不会擅自移动原文件
- 只有明确点击移动 / 确认处理后才会改动原照片位置
- 所有删除操作默认进入 Windows 回收站，可从系统回收站恢复
- 默认将处理结果放在原照片所在目录的 `PhotoCurator_Result（照片筛选结果）` 中
- 高级设置可改为统一放到所选大文件夹或自定义输出目录
- 重复导出不会覆盖上一次 TOP 结果
- 动态本地端口，5014 被占用时桌面版自动寻找可用端口
- 单实例保护，避免两个窗口同时修改同一图库
- 启动错误完整日志
- GitHub 自动检查 Python、嵌入 JavaScript、HTML 结构和响应式 CSS

## GitHub Codespaces 在线预览

> **内置测试数据**：程序会固定保留 12 张基准测试照片（清晰 4、轻微软 4、模糊 4）。已有文件不会被覆盖；测试移动走后，下次刷新/启动会自动补回缺失的基准样例。


不下载项目到电脑，也可以先在 GitHub Codespaces 中查看和测试最新版界面与核心处理流程。

推荐流程：

1. GitHub 仓库点击 **代码 → 代码空间（Codespaces）→ 创建代码空间**
2. 第一次使用新版配置时，按 `Ctrl + Shift + P`，执行 **Codespaces: Rebuild Container**
3. 打开 Codespaces 终端，运行：

```bash
bash 在线预览.sh
```

4. 等待依赖安装与服务启动。新版会把 Flask 服务放到后台常驻，并在启动后自动做本地健康检查；Codespaces 检测到 **5014** 端口后，在“端口”面板点击浏览器图标即可打开在线预览

在线预览和 Windows 桌面版共用同一组“内置测试数据”，界面左侧可直接进入并验证三步流程。

需要注意：

- Codespaces 运行在 GitHub 云端，**不能直接读取你电脑的 C: / F: 等本地硬盘**
- 如需测试自己的照片，可以把少量样片上传到 Codespaces 工作区，再把对应云端路径粘贴到“照片文件夹”
- 5014 转发端口建议保持 GitHub 默认的 **Private（私有）**，不要改成 Public
- Windows 桌面版仍保持仅监听本机 `127.0.0.1`；只有检测到真实 Codespaces 环境并成功推导出当前 Codespace 的专属转发域名时，才启用云端预览监听
- 在线预览主要用于界面、API 与核心算法验证；Windows 原生文件夹选择器、WebView2、DPI 和本机大硬盘性能仍需 Windows 真机测试
- 内置测试数据由程序自动生成并补齐缺失样例；不会覆盖用户自行上传的样片

### 模糊照片移动前复核

模糊筛选完成后，算法判定为“模糊”的照片默认加入待移动列表，但文件不会立即移动。

- 每张模糊照片左上角都有独立勾选按钮，可取消或重新加入本次移动
- 顶部提供“全选 / 全不选”，并实时显示“待移动 X/Y”
- 底部按钮实时显示实际将移动的照片数量
- 取消勾选只影响文件移动，不会修改照片的“模糊”分类结果
- 手动将照片从“模糊”改为“清晰/轻微软”时会自动退出待移动列表
- 手动将照片改为“模糊”时会默认加入待移动列表
- 大图预览中也可以切换“本次移动 / 保留原位”
- 点击移动后，只移动已勾选的模糊照片；默认存入原目录下的 `PhotoCurator_Result（照片筛选结果）/Blurred（模糊照片）`
- 未勾选照片保持原位置

## Windows 正式版

正式版对普通用户只保留三件事：

1. **安装**：运行 `PhotoCurator-Setup-v1.4.2.exe`，安装目录可自由选择
2. **打开**：安装后从桌面或开始菜单打开 `PhotoCurator`
3. **卸载**：从 Windows“设置 → 应用”卸载 PhotoCurator

程序、运行环境、缓存、日志和配置都放在用户选择的安装盘内。安装目录结构由安装器管理；用户不需要安装 Python，也不需要运行 BAT/CMD。

卸载默认不会删除任何原照片、筛选结果或自定义输出目录。缓存和日志会清理，设置会在卸载时单独询问是否删除。

开发仓库中的 BAT/CMD 仅作为维护和源码运行工具，不属于正式版用户入口。

## 后续更新方式

PhotoCurator 使用固定应用标识进行**原位覆盖升级**：

1. 下载新版 `PhotoCurator-Setup-vX.X.X.exe`
2. 直接运行，不需要先卸载旧版
3. 安装器自动沿用原安装目录
4. 仅覆盖 `app` 程序文件
5. `data` 中的设置、本地索引、操作日志和缓存策略数据继续保留
6. 原照片、筛选结果、自定义输出目录永远不参与程序覆盖

如果以后安装位置从 D 盘改到其他盘，建议先正常卸载程序再重新安装到新位置；卸载仍不会删除原照片和筛选结果。


## 窗口与缩放

- 主图库：**Ctrl + 鼠标滚轮** 调整缩略图尺寸和每行照片数量
- 普通滚轮：页面上下滚动
- 大图查看：滚轮缩放照片、拖拽平移、双击在适应窗口 / 2 倍之间切换
- 顶部不再显示页面缩放百分比
- 桌面版采用无边框窗口外壳；右上角关闭按钮默认最小化，避免误关正在进行的任务

## 文件安全

默认原则：**先分析、再审核、最后由用户明确决定。**

- “删除”默认进入 **Windows 回收站**，不直接永久删除原文件
- 手动切换分类只修改审核状态，不擅自移动原文件
- 相似组至少保留 1 张，可人工增加保留项
- TOP / 精选导出使用复制，不移动原照片
- 用户手动决定的“保留 / 模糊 / 是否移动”等状态优先于后台后续刷新
- 程序生成目录继续自动排除，避免处理结果重新进入扫描

## 大图库与增量扫描

默认扫描范围为 **当前文件夹 + 所有子文件夹**。

v1.4.2 使用长期本地照片索引：

- 第一次扫描计算清晰度基础指标并写入本地索引
- 再次扫描同一照片时先比较文件大小与修改时间
- 未变化的照片直接复用历史分析结果，不重新解码和计算；不会因为几个月没打开就自动失效
- 清晰度与智能评分改为批量读取本地索引，避免大图库逐张打开数据库；相似分析继续复用已有感知特征缓存
- 新增或修改过的照片才重新分析
- 扫描结果按来源文件夹累计展示，完成一个文件夹即可先操作一个
- 运行记录与关键文件操作会写入本地操作日志
- 分析中可切换到已经完成的结果视图继续复核；文件夹内相似分析完成一组即可先查看和选择保留项
- 清晰度人工复核和相似组保留选择会动态影响后续精选结果；照片改成“模糊”后不会再被当作相似组保留项或重复照片移动
- 人工“清晰 / 轻微软 / 模糊”和“是否移动”会按文件状态保存；照片文件本身发生变化后旧人工结论自动失效
- 运行中的结果使用受控实时载荷，完成后按块继续载入，减少大图库频繁传输导致的卡顿
- 相似分析只在内存保留真正的重复组，唯一照片使用紧凑路径集合保存，降低大图库内存占用
- 单次“开始分析”会锁定当次参数；中途切换结果页不会改变后续阶段的处理范围
- 如果清晰度阶段没有任何可继续处理的照片，后续相似分析和精选评分会直接结束，不会重新把原照片扫回来

传统“第几页”分页已取消，浏览改为文件夹分组和缩略图懒加载。

## 数据与网络

照片分析、缩略图、RAW/HEIC 解码均在本机执行，不上传照片。

可选 GPS 地图查看功能需要访问 OpenFreeMap 地图瓦片。打开带定位信息的照片详情并解析“具体地点”时，程序会把经纬度发送给 OpenStreetMap Nominatim 做地点解析；照片文件本身不会上传。除此之外，核心筛选流程不依赖云端服务。

## 项目结构

- `desktop_app.py`：桌面窗口和本地服务启动器
- `photo_curator.py`：主界面、API 和流程编排
- `photo_dedup_batch.py`：相似照片聚类去重
- `photo_ranking_v3.py`：照片质量评分
- `photo_file_organizer.py`：照片移动 / 导出
- `raw_loader.py`：RAW / HEIC 加载
- `vendor/`：本地 MapLibre 资源
- `.github/workflows/syntax-check.yml`：自动语法检查
