# PhotoCurator 中文桌面版

> 基于 Photo Curator 二次开发的 Windows 照片筛选工具，核心流程是“清晰度分析 → 相似组选优 → 精选推荐 → 软件回收站复核”。

| 项目 | 信息 |
| --- | --- |
| 当前版本 | **v1.4.2** |
| 项目类型 | Windows 照片筛选桌面应用 |
| 上游基线 | Photo Curator v7.0 |
| 当前状态 | 正式发布 / 持续维护 |

---

## 项目概览

PhotoCurator 中文桌面版在保留原项目核心算法思路的基础上，重点完善 Windows 桌面使用体验、大图库性能、人工复核逻辑、文件安全和正式安装发布流程。

支持 JPEG、PNG、WebP、TIFF、BMP、HEIC/HEIF/HIF，以及 CR2、CR3、NEF、ARW、DNG、RAF、ORF、RW2、PEF 等常见 RAW 格式。

---

## 核心能力

### 清晰度分析
- 清晰 / 轻微软 / 模糊分类
- 模糊照片先筛选、后处理
- 每张照片可单独取消或重新加入移动列表
- 手动修改分类不会擅自移动原文件

### 相似组选优
- 文件夹内对比 / 全局对比
- 相似组先自动筛选，再人工复核
- 每组可同时保留多张
- 至少保留 1 张
- 人工选择会继续影响后续精选结果

### 精选推荐
- 基于清晰度、相似关系与质量评分生成精选结果
- TOP / 精选导出使用复制，不移动原照片
- 重复导出不会覆盖上一轮结果

### 软件回收站
所有普通“删除”先进入：

```text
PhotoCurator_RecycleBin（软件回收站）
```

支持：
- 缩略图 / 大图最后复核
- 单张恢复原位
- 全部恢复
- 单张永久删除
- 清空回收站

只有在回收站中再次确认永久删除后，文件才会真正从磁盘移除。

### 大图库与增量扫描
- 默认支持当前文件夹 + 所有子文件夹
- 长期本地照片索引
- 未变化照片复用历史分析结果
- 相似特征和拍摄时间进入长期索引
- 新增或修改照片才重新分析
- 受控实时载荷与分块加载
- 缩略图懒加载
- 运行记录与关键文件操作日志
- 程序生成目录自动排除，避免重复扫描

### Windows 桌面体验
- 原生文件夹选择
- 默认最大化启动
- Ctrl + 鼠标滚轮调整缩略图尺寸
- 125% / 150% / 200% DPI 适配
- 动态本地端口
- 单实例保护
- 启动错误日志

## 快速开始

普通用户只需要：

1. 下载 `PhotoCurator-Setup-v1.4.2.exe`
2. 双击安装
3. 从桌面或开始菜单打开 PhotoCurator

正式版不要求用户自行安装 Python，也不要求运行 BAT/CMD。

已安装旧版时可直接覆盖安装。

## 在线预览

GitHub Codespaces 可用于验证界面、API 与核心处理流程。


## 更新方式

PhotoCurator 使用固定应用标识进行原位覆盖升级：

1. 下载新版安装包
2. 直接运行，无需先卸载旧版
3. 安装器沿用原安装目录
4. 仅覆盖程序文件
5. 设置、本地索引、操作日志和缓存策略继续保留
6. 原照片、筛选结果、自定义输出目录和软件回收站不参与覆盖

## 数据、安全与使用边界

默认原则：**先分析、再审核、最后由用户明确决定。**

- 普通删除不直接永久删除
- 手动分类不擅自移动原文件
- TOP / 精选导出使用复制
- 恢复时不覆盖已有同名文件
- 软件回收站自动从后续扫描中排除
- 照片分析、缩略图、RAW/HEIC 解码均在本机执行
- GPS 地图功能可能将经纬度发送给地图 / 地理编码服务，但不会上传照片文件
