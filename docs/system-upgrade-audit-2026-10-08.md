# PhotoCurator-CN 系统级升级审计基线（2026-10-08）

> 状态：审计与实施设计，不代表功能已修复、Windows 测试已通过或新版本已发布。此分支不改动 main 业务代码。

## 已在 main 源码确认的缺陷与关联

1. `photo_curator.py / activateStep()`：切换核心页面会覆盖 `gallery.innerHTML`，重置 `gPage`、`gItems`、`lastGallerySig` 及结果签名。与“离开页面后结果消失、重新加载、滚动位置丢失”直接相关。应改为每数据源/每模块独立的浏览状态，按需恢复可视窗口，不能永久保留全部 DOM。
2. `photo_curator.py / resetWorkspaceForFolder()`：切换目录清空 `cullLiveStore` 和 `dedupLiveStore`，同时重置统计与展示。当前行为对于更换根目录不够友好，也无法直接满足“选中仅查看、不重新筛选”。需将缓存键绑定稳定的 source/root 身份，区分清屏、切换、扫描和刷新动作。
3. `photo_curator.py / renderCullStep()`：设置 `gPage=0`，每次结果变更可能导致列表分页和浏览位置改变。需要滚动锚点与稳定结果键。
4. `photo_curator.py / renderDedupGroups()`：仍输出「完成本组」按钮，且组内展示有「推荐保留」「✓ 保留」等旧语义。按用户新要求，照片人工操作仅「正常／待删除」，分组进度独立自动计算；在移除按钮前必须迁移原按钮承担的写入、状态更新逻辑。
5. `photo_curator.py / loadCullPage()/loadDedupPage()`：使用内存 Map 和按 200 条分页获取；需验证跨页面、跨来源与实时新增情况下的游标、排序、总数一致性，以及请求返回乱序处理。
6. `photo_curator.py / applyDedupSelection()`：成功响应后 `dedupLiveStore.clear()` 并重建结果。需将实际文件操作结果与人工标记状态解耦，避免处理完成或失败时丢失浏览锚点及已标记状态。
7. `catalog.py`：`media_catalog` 使用 `UNIQUE(root_id, relative_path)`；父子 root 可能重复引用同一物理文件，必须验证实际媒体身份去重与统计重叠处理，不能只靠 UI 改树。
8. `background_tasks.py`：已经具备持久化任务、worker、幂等键与崩溃任务重新入队。不得另建第二套队列；需检查实际文件操作幂等性、重新入队后事务恢复与设备离线行为。
9. `README.md`：当前 README 声明源码 v1.7.2 Candidate、Stable 下载 v1.5.0；不能把 Candidate 验证视作已正式发布。

## 产品层面的统一不变量

- 分析中、暂停及完成时，已保存图库都能浏览、筛选、撤销；后台新增数据不能移动用户正在点击的卡片。
- 人工照片标记只有「正常」「待删除」；算法结果、分组进度、文件生命周期分别建模。
- 所有普通删除先标记，再经明确确认进入持久文件操作队列；支持撤销、回收站、恢复、失败重试。
- 正常与待删除有明显颜色、边框、标签及按钮差异，但照片原始视觉保持清晰。
- 相似分组筛选状态自动计算；新成员引发复核但不覆盖既有人工决定。
- 顶部小型进度常驻，显示数量与百分比，点击展开覆盖式详细面板；只有成功状态变绿。
- 主题设计为 Aurora Bubble Glass：鲜亮极光背景、明显毛玻璃、适度泡泡胶囊、优先保持专业图库性能。
- 历史数据与已发布安装版本必须兼容；每次代码更新同步提升版本号。

## 实施次序与门禁

1. 源码数据契约：设备/source/root/media/analysis/task/decision 的身份、所有权、状态机及统计定义。
2. UI 生命周期：分来源/模块缓存、请求过期保护、视图锚点与局部更新。
3. 选择与处理：统一待删除状态、自动分组状态、文件安全及中断恢复。
4. 交互布局：紧凑分组、放大字体、重组侧栏、顶部进度浮层。
5. Aurora Bubble Glass：设计令牌、浅深配色、玻璃层级、微动效和简化动画模式。
6. 性能、Windows 构建、安装升级与数据库迁移回归。

### 必须通过的测试场景

- 父子根目录同时添加；盘符变化及拔插；离线索引读取；重启后选中状态恢复。
- 边分析边操作；连续点击 50 张不位移；切换页面 20 次保持滚动/展开/选择。
- 模糊扫描、相似组增量重组；所有状态统计一致，不提前成功，不重复新增。
- 批量删除中断、复制后断电、权限错误、部分成功、恢复和重复重试；RAW/JPG/XMP 关联。
- 19000+ 文件、后台并行任务下的 CPU/内存/磁盘/帧率基准；Windows DPI 100/125/150%。
- 数据库备份、覆盖升级、旧 Stable 数据迁移；Windows 安装器产物、签名和发布门禁。

## 限制

此基线通过 GitHub 连接读取源码获得；尚未具备可执行的完整 Windows 测试环境。未经回归，不允许宣称发布级更新完成或将高风险文件处理变更直接推入 main。
